# Working（企微 / QQ 保活）

> 防止电脑休眠，并通过定期保活事件提升企业微信 / QQ 在线状态保持成功率的工具。

支持 **macOS** 与 **Windows**。菜单栏 / 托盘轻量运行，可设定工作时间段，下班自动停止。

3. 可在托盘图标中查看状态与设置

## 功能概览

- **防休眠** — Mac 使用 IOKit 电源断言，Windows 模拟 NumLock 等保活策略
- **微位移保活** — 定时发送极小鼠标位移并回到原位，提高被识别为「活跃」的概率
- **增强保活（Mac）** — 可选 F15 后备事件，企微仍显示「离开」时可开启
- **工作时间** — 自定义起止时间，非工作时段自动停止
- **轻量常驻** — Mac 菜单栏 / Win 系统托盘，不打扰日常使用

## 常见问题

### Q: Mac 提示「无法打开，因为无法验证开发者」

**A**: 正常现象（免费签名）。任选其一：

**方法 1（推荐）**：右键应用 →「打开」→ 对话框中点「打开」

**方法 2**：

```bash
xattr -cr /Applications/Working.app
```

**方法 3**：系统设置 → 隐私与安全性 → 安全性 →「仍要打开」

### Q: 为什么需要无障碍 / 辅助功能权限？（Mac）

**A**: 模拟鼠标移动需要该权限。除每日验证外**不联网**，不收集使用数据。

### Q: 会影响正常使用电脑吗？

**A**: 默认模式位移极小且会回到原位置，一般无感。Mac 的「增强保活」会额外发送 F15，建议仅在企微仍变「离开」时开启。

### Q: 手动锁屏后还有效吗？

**A**: **无效**。锁屏后系统限制输入事件，与 Windows 版行为一致。

### Q: 企业微信还是显示「离开」怎么办？

**A**:

1. 确认辅助功能权限已授予（Mac）
2. 确认当前时间在设定的工作时间范围内
3. 确认主界面「运行摘要」为 **保活事件正常**
4. Mac：若屏幕常亮但 5～10 分钟后仍离开，开启 **增强保活模式** 再观察约 15 分钟
5. 若仍无效，可能是当前企微版本未将此类系统事件计为有效在线操作

### Q: 旧版还能用吗？

**A**: v1.0.1 起验证服务已迁移至 `verify.19930312.xyz`。写死旧 IP 的版本无法验证，请从上方下载页安装最新版。

### Q: 如何卸载？（Mac）

```bash
rm -rf /Applications/Working.app
# 可选：删除配置
defaults delete com.yourname.Working
```
